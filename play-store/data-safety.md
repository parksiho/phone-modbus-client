# 데이터 보안 양식 초안

Play Console **정책 → 앱 콘텐츠 → 데이터 보안** 에 옮길 때 쓰는 초안입니다. AdMob 이 실제로 수집하는 항목은 계정 설정과 SDK 버전에 따라 달라지므로, 제출 전에 [Google Play 데이터 공개 가이드](https://support.google.com/googleplay/android-developer/answer/10787469) 와 AdMob 의 현재 데이터 공개를 다시 대조합니다.

개인정보처리방침 URL 은 `privacy-policy.md` 를 올린 공개 주소입니다. `privacy@example.com` 은 자리표시자입니다.

## 앱이 직접 하지 않는 일

개발자 서버로 나가지 않으므로 **수집·공유로 표시하지 않습니다.**

- Modbus 요청·응답, 레지스터 값, Ping 결과, 화면 로그
- 이용자가 입력한 장비 IP, 앱 IP, 포트, Unit ID (SharedPreferences, 기기 안에만 있음)
- USB 장치 정보

이 데이터는 폰과 USB 어댑터 사이에 머뭅니다.

## 수집·공유로 답할 항목 (AdMob)

앱은 이용자 계정이 없습니다. 아래는 광고 SDK 가 기기 밖으로 보내는 데이터입니다. 수신자는 Google (AdMob) 입니다.

| Play 데이터 유형 | 수집 | 공유 | 목적 | 비고 |
|---|---|---|---|---|
| 기기 또는 기타 ID → 광고 ID | 예 | 예, Google | 광고 또는 마케팅 | 필수에 가깝습니다. 앱이 서버에 저장하지는 않습니다. |
| 앱 활동 → 앱 상호작용 | 예 | 예, Google | 광고 또는 마케팅 | 광고 노출·클릭. 앱 자체의 버튼 조작을 개발자가 수집하지는 않습니다. |
| 앱 정보 및 성능 → 비정상 종료 로그 / 진단 | 선택 | 선택 | 분석 또는 광고 | AdMob 이 진단 데이터를 보내는 경우에만 예. 개발자용 Crashlytics 는 없습니다. 확신이 없으면 AdMob 데이터 공개를 보고 맞춥니다. |
| 위치 → 대략적인 위치 | 선택 | 선택 | 광고 | IP 기반 대략적 위치를 AdMob 이 쓰면 예. 앱은 위치 권한이 없고 GPS 를 읽지 않습니다. |
| 개인정보, 금융, 사진, 연락처, 메시지, 오디오, 파일, 캘린더, 웹 방문 기록, 건강 | 아니오 | 아니오 |  | 해당 없음 |

## 보안 질문

- 전송 중 암호화: **예.** 수집되는 광고 트래픽은 HTTPS 입니다. 기기 안에만 있는 Modbus 데이터는 이 질문의 "수집"에 넣지 않습니다.
- 데이터 삭제를 요청할 방법: **예, 개인정보처리방침의 연락처.** 개발자 서버에 계정은 없습니다. 방침에 앱 삭제·저장소 삭제·광고 ID 재설정을 적고, 자리표시자 이메일을 실제 주소로 바꿉니다. Play 가 URL 을 요구하면 방침의 삭제 섹션 주소를 넣습니다.
- 가족이 정책 / 아동: 아동용이 아님. 교사 승인 프로그램이 아님.

## 광고 ID 선언 (별도 양식)

**정책 → 앱 콘텐츠 → 광고 ID**

- 앱이 광고 ID 를 사용하나요: **예**
- 목적: 광고 또는 마케팅
- 분석만 쓰고 광고에 안 쓴다는 답은 하지 않습니다. 배너가 있습니다.

## 광고 선언 (별도 양식)

**정책 → 앱 콘텐츠 → 광고**

- 앱에 광고가 있나요: **예**
- 배너만 해당합니다. 전면, 앱 오픈, 보상형은 없습니다.

## 제출 전에 개발자가 확정할 것

- AdMob 계정에서 이 앱의 데이터 공개와 위 표가 같은지
- 대략적인 위치와 진단 로그를 "예"로 둘지. 모르면 AdMob 문서를 보고 맞추고, 빠뜨리는 쪽보다 고지하는 쪽이 안전합니다.
- 개인정보처리방침의 이름, 시행일, `privacy@example.com`
- `ads.xml` 의 테스트 ID 를 실제 앱 ID·배너 단위로 바꾼 뒤에만 스토어 빌드를 업로드
