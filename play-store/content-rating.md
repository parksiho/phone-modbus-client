# 콘텐츠 등급 (IARC) 설문 초안

Play Console **정책 → 앱 콘텐츠 → 콘텐츠 등급** 에서 설문은 그때의 IARC 문항을 따릅니다. 아래는 이 앱의 실제 기능에 맞춘 답입니다. 콘솔이 계산한 등급이 최종입니다. 광고 소재가 넓으면 등급이 올라갈 수 있습니다.

카테고리 후보: **유틸리티 / 도구**. 게임, 소셜, 데이팅이 아닙니다.

| 주제 | 답 | 이유 |
|---|---|---|
| 폭력, 공포, 사실적 피해 | 없음 | 통신 점검 도구입니다. |
| 성적 콘텐츠, 노출 | 없음 | |
| 욕설, 비속어 | 없음 | 앱 문구에 없습니다. |
| 규제 약물, 술, 담배 | 없음 | |
| 도박, 시뮬레이션 도박, 현금 보상 | 없음 | |
| 이용자가 서로 대화·프로필·위치 공유 | 아니오 | 계정도, 이용자 간 통신도 없습니다. |
| 이용자 생성 콘텐츠를 다른 이용자에게 공개 | 아니오 | 로그와 레지스터 값은 그 폰에만 있습니다. |
| 위치 공유 | 아니오 | 위치 권한이 없습니다. |
| 디지털 상품 구매, 랜덤 아이템 | 아니오 | 인앱 결제가 없습니다. |
| 제한 없는 웹 브라우저 | 아니오 | 브라우저가 없습니다. 광고 클릭이 외부 페이지를 열 수는 있습니다. |
| 광고가 포함되나요 (문항이 있으면) | **예** | 하단 배너. |

예상되는 등급대는 전체이용가(PEGI 3, ESRB Everyone 부근)입니다. 보장하지 않습니다.

광고 때문에 등급이 올라가는 것을 막으려면, 스토어 빌드 전에 AdMob 과 `RequestConfiguration.setMaxAdContentRating` 으로 상한을 둘지 정합니다. 지금은 코드에서 상한을 지정하지 않습니다.
